## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# out/entry.png is the 1024x1024 image
```

`main.py` uses only the Python standard library: it validates the pre-drawn `entry.png` (PNG, at most 1 MiB, at most 1024x1024) and copies it byte for byte to the output directory.
